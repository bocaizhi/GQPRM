# GQPRM: Precise Dynamic Pricing for Graph Query-based Data Transaction

Graph query-based data pricing is promising to price each subgraph separately in graph database to accommodate data combinations for needs of diverse users. However, existing methods fail to address the vital issue of precise data price updates due to the fundamental challenge in balancing broker revenue and transaction success rate. To bridge the gap, we propose GQPRM, a dynamic graph query-based data pricing framework, including: (1) We propose a vertex-edge pricing mechanism, which enables broker to determine the price of subgraph when it is first queried by a buyer. And the mechanism is theoretically proven arbitrage-free. (2) For repeatedly queried subgraphs, the broker has to find the way to update each subgraph price on each query. We formulate the pricing task as a multi-armed bandit (MAB) problem and adopt an exploration-exploitation strategy driven by historical price variations of the subgraph to balance high broker revenue with high transaction success rate. (3) Furthermore, we employ the entropy weight method integrating the centrality, query frequency and transaction success rate of each vertex and edge within the subgraph as parameters to distinguish the contribution weight of each vertex and edge to the latest price variation, which allows the broker to update the prices of vertices and edges accurately. (4) We design a smart contract-based incentive allocation mechanism, which establishes precise incentive allocation rules between the data broker and data owners. The superiority of GQPRM in maximizing broker revenue and transaction success rate is demonstrated through extensive experiments on multiple typical datasets.
